# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my projects, please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting via the repository's **Security** tab, or contact me through my website.

I aim to acknowledge reports within 7 days and will keep you updated on progress towards a fix.

## Supported Versions

Security fixes are applied to the latest release of each project.
